# PS No. 43 – Bus/Train Ticket Booking System

## Project Overview
A simple console-based Bus/Train Ticket Booking System developed using Python 3.

## Features
- Manage 10 seats
- View available and booked seats
- Book tickets for passengers
- View booking details
- Cancel tickets
- Calculate an 80% refund on cancellation

## Project Rules
- Total seats: 10
- Ticket price: ₹500
- Cancellation refund: ₹400

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Open the project folder in VS Code.
2. Open the `codebase` folder.
3. Run `main.py` using Python.
