# PS No. 43 – Bus/Train Ticket Booking System

## 1. Introduction
The Bus/Train Ticket Booking System is a Python-based console application. It helps users manage seat availability, book tickets, view booking details, and cancel tickets.

## 2. Objectives
- To manage 10 seats.
- To display available and booked seats.
- To book tickets for passengers.
- To store and display booking details.
- To cancel bookings and calculate refunds.

## 3. Technologies Used
- Programming Language: Python 3
- Code Editor: Visual Studio Code

## 4. Features
1. View Seats
2. Book Ticket
3. View Bookings
4. Cancel Ticket
5. Exit

## 5. Project Rules
- Total seats: 10
- Ticket price: ₹500
- Cancellation refund: 80%
- Refund amount: ₹400

## 6. Python Concepts Used
- Dictionaries
- For loop
- While loop
- If-elif-else conditions
- User input
- Input validation

## 7. Working of the Project
The program displays a menu to the user. The user can select an option to view seats, book a ticket, view booking details, or cancel a ticket. When a ticket is cancelled, the seat becomes available again and an 80% refund is calculated.

## 8. Conclusion
The Bus/Train Ticket Booking System demonstrates basic Python programming concepts through a simple ticket booking application. It provides basic seat management and booking operations.
